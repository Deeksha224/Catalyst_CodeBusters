# ⚡ Catalyst — Tech Event by Code Busters Club, GLAU

Welcome to **Catalyst**, the official tech event organized by the **Code Busters Club, GLA University** 🎯.  
This repository hosts the source code for the **Catalyst Event Website**, where participants can explore event details, register for multiple tech activities, and stay updated with the latest announcements.

---

## 🚀 About the Project

The **Catalyst Event Website** is designed to make event participation effortless and engaging.  
It provides a one-stop platform for:
- 🎫 **Event Bookings & Ticket Registration**
- 📰 **Live Event Updates & Announcements**
- 🗓️ **Detailed Schedules, Rules, and Venues**
- 💬 **Community Engagement & Highlights**

Our mission is to blend **technology and creativity** to create an immersive experience for every participant of Catalyst.

---

## 🖥️ Tech Stack

| Category | Technology |
|-----------|-------------|
| **Frontend** | React + Vite ⚡ |
| **Styling** | Tailwind CSS 🎨 |
| **Backend / Auth** | Supabase 🔐 |
| **Hosting** | Vercel / Netlify 🌍 |
| **Version Control** | Git & GitHub 🧭 |

---

## ✨ Key Features

- 🔐 **User Authentication:** Secure signup & login with Supabase  
- 🎟️ **Booking System:** Easy registration for different events  
- 🗓️ **Dashboard View:** Access event details, categories, and timings  
- 📰 **Live Announcements:** Get instant updates during the event  
- 🧾 **Ticket Access:** View or download digital passes  
- 🌙 **Dark Tech Theme:** Minimalistic and futuristic UI reflecting Code Busters’ identity

## 🛠️ Installation & Setup

Follow the steps below to run the project locally 👇

```bash
# Clone the repository
git clone https://github.com/Deeksha224/Catalyst_CodeBusters.git

# Move into the project folder
cd Catalyst_CodeBusters

# Install dependencies
npm install

# Start the development server
npm run dev
